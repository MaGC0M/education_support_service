# Бюро — служба поддержки

Учебное веб-приложение для работы с заявками в службу поддержки. Бэкенд написан на Python с FastAPI, интерфейс — на HTML, CSS и JavaScript.

Бэкенд проекта написал автор репозитория. Фронтенд создан с помощью ИИ (ChatGPT) для демонстрации работы с API.

## Возможности

- Создание заявок с темой, описанием и автором.
- Просмотр списка, поиск в интерфейсе и фильтрация по статусу.
- Назначение оператора и перевод заявки из новой в работу, затем в закрытую.
- Добавление комментариев и просмотр обсуждения.
- Удаление новых заявок.
- Адаптивный интерфейс со светлой темой.

Бизнес-правила проверяются на бэкенде. Например, начать работу можно только после назначения оператора, а закрыть заявку — после добавления комментария.

## Технологии

- Python, FastAPI, Pydantic, Uvicorn.
- HTML, CSS, JavaScript без фреймворков.
- Node.js для раздачи интерфейса и проксирования запросов к API.

## Требования

- Python 3.10 или новее.
- Node.js 22 или новее с npm.

## Установка и запуск

Скачайте репозиторий и откройте терминал в корневой папке проекта. Команды ниже приведены для Windows PowerShell.

### 1. Установите зависимости бэкенда

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r req.txt
```

### 2. Запустите API

В первом терминале из корня проекта выполните:

```powershell
.\.venv\Scripts\python.exe -m uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

Документация API со встроенной отправкой запросов доступна по адресу [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs).

### 3. Запустите интерфейс

Откройте второй терминал в корневой папке проекта:

```powershell
cd frontend
npm run dev
```

Устанавливать npm-пакеты не требуется — сервер интерфейса использует встроенные модули Node.js.

Откройте [http://127.0.0.1:5173](http://127.0.0.1:5173). Оба терминала должны оставаться запущенными. Для остановки нажмите `Ctrl+C` в каждом терминале.

## Структура проекта

```text
main.py            — HTTP-эндпоинты FastAPI
domain.py          — класс заявки и бизнес-правила
service.py         — создание, хранение, поиск и удаление заявок
schemas.py         — модели запросов и ответов, валидация данных
req.txt            — зависимости Python
frontend/          — интерфейс и локальный Node.js-сервер
```

## Как связаны фронтенд и бэкенд

Интерфейс отправляет запросы на `/api/*`. Сервер `frontend/server.mjs` перенаправляет их в FastAPI по адресу `http://127.0.0.1:8000`. Это позволяет браузеру работать через один адрес без дополнительной настройки CORS в бэкенде.

Адрес бэкенда можно изменить через переменную окружения `API_URL`, порт интерфейса — через `PORT`.

## Ограничения учебной версии

Заявки хранятся в памяти одного процесса, без базы данных. При перезапуске API все заявки исчезают. Имя для заполнения форм сохраняется локально в браузере.

Авторизация и разграничение прав пока не реализованы. Проект предназначен для локального запуска и изучения разработки API(возможно в будущем подключу БД).
